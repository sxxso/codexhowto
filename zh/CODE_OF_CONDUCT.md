# 行为准则

## 我们的承诺

作为成员、贡献者和维护者,我们承诺让每个人参与 codexhowto 的过程都免受骚扰,无论年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教,或性取向与性别认同如何。

## 我们的准则

有助于营造积极环境的行为包括:

- 尊重不同的观点、看法和经历
- 给出并优雅地接受建设性反馈
- 以社区和学习者的最大利益为出发点

不可接受的行为包括:

- 任何形式的骚扰,无论公开还是私下
- 挑衅、侮辱或贬损性言论,以及人身或政治攻击
- 未经明确许可公开他人的隐私信息

## 执行

任何辱骂、骚扰或其他不可接受的行为,均可向项目维护者举报。所有投诉都会得到及时、公正的审查与调查。

本行为准则改编自 [Contributor Covenant](https://www.contributor-covenant.org/) 2.1 版。
